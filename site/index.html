Questions and the fine print

Spotifry is a hobby project, made for personal use and for learning. Here is what it is and what it isn’t.

  • NewPipe Extractorreads YouTube
  • Media3 / ExoPlayerplays the songs
  • SponsorBlockfinds the talking
  • BetterLyrics, LRCLIBbring the lyrics
Read the full disclaimer
Does Spotifry cost anything?

No. No ads, no paid features, no subscription, no account, and it collects no personal data.

Is it safe to install an APK from GitHub?

Every release is signed with the same key, and Android only installs an update when the key matches. The source code is public, so anyone can read what the app does.

Will it work on my phone?

Spotifry needs Android 8 or newer. It isn’t on the Play Store; you install the file from GitHub Releases once, and the app updates itself after that.

Does Spotifry host any music?

No. Songs stream from YouTube and belong to their owners. Saved songs stay on your phone.

Is Spotifry made by YouTube or Spotify?

No. It isn’t affiliated with or endorsed by YouTube, Google or Spotify.

What if YouTube search breaks?

YouTube changes its site now and then. Search stays broken until NewPipe Extractor is fixed and a new release comes out.

How do I support the artists behind the music?

Pay for YouTube Music Premium or Spotify Premium if you can, buy their music, go to their shows.
