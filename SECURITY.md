# Security

## Report a problem

If you find a security problem, please do not open a public issue. Use the **Security** tab of this repository and choose **Report a vulnerability**, so only the maintainer sees it. Say what you found and how to reproduce it.

You can expect an answer within a few days. A fix ships in the next release, and you are credited if you want to be.

## What is supported

Only the latest release gets fixes.

## What Spotifry stores

Spotifry has no accounts and no server of its own. Your lists, history and settings stay on your device.
